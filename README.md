# Ecommerce Web Application

A production-focused web application built using Next.js, TypeScript, and modern frontend best practices.

## Tech Stack
- Next.js
- React
- TypeScript
- Tailwind CSS
- REST APIs

## Features
- Responsive, mobile-first UI
- API-driven data fetching
- Authentication-protected routes
- State management using React Context API
- Performance and SEO optimization

## Testing
- Basic unit and component testing using Jest and React Testing Library
